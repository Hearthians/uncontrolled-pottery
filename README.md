# 失控陶坊 / Uncontrolled Studio

实时生成的三维陶土打印装置原型，使用 React、TypeScript、Vite 和 Three.js。

```sh
npm install
npm run dev
```

打开 Vite 输出的本地地址。远程 CLI 或 VS Code 可直接转发该端口。公网体验入口为 <https://gfyh.fun/pottery/>。

每次完整打印的目标播放时长约 55 秒，共 64 圈，包含停料余流与收尾；实际耗时取决于浏览器性能。当前作品由 Agent 从 1910 条公开集体记忆中编排出的十二段情绪轨迹自动驱动；确定性映射器只把效价、唤醒度与控制感转换为逐层供料波动和中断，材料性质始终相同。用户不再手动修改创作参数，只保留开始、暂停、继续和结束。提前结束只保留已经走过的情绪段落，不会把剩余轨迹压缩到收尾阶段。

完成后可以命名收藏、旋转查看、回看参数时间轴，并导出 JSON 过程记录及 WebP 图像。画廊工具栏的导入图标可以重新打开 JSON 记录。收藏保存在当前浏览器的 localStorage 中；默认新打印使用 v3 浏览器黏塑性泥条原型（可在开始前选择实验 v4），存档包含模拟版本、配置标识、固定步长、种子、供料事件和实际欠供料脉冲。v1/v2 作品按原算法重建，内置试作仍为 v2，不会静默迁移；导出包装版本与对应材料配置一致。

v3 保留气压直挤式供料近似与固定螺旋喷嘴路径，配置为直径 100 mm、喷嘴 6 mm、层高约 1.92 mm、速度 25 mm/s；约 823 秒的模型时间压缩至目标 55 秒播放。泥条采用固定子步、空间接触和黏塑性约束，探索支撑缺失、压扁与拉伸断开后的形态变化，不通过情绪切换材料性质。它不是经实机标定的陶土流变或有限元求解器，不保证真实盘曲、整件倒塌或可打印性，也不模拟干燥和烧成。调研依据见 [调研方案](docs/clay-printing-research-and-plan.md)；[v2 历史预览说明](docs/material-preview-1.md) 保留原发布与回退记录，不作为 v3 已部署或已验收的声明。

### v3 物理原型的边界

- 每个材料 tick 细分为 4 个固定子步，每子步进行 3 轮拉伸、弯曲、接触与平台约束；更新与屏幕帧率无关。
- 空间网格寻找附近泥条，接触后截面逐步压扁；摩擦限制侧向滑动，超过屈服阈值后修改静止曲率，过度拉伸时断开连接。稳定片段休眠，支撑移动或新增载荷可唤醒它们。
- 接触使用截面样本近似，压扁目标仍依赖配置层高，载荷按单个较低旧样本传递；这不是连续表面碰撞或完整应力分布。黏性用强阻尼近似，尚无经标定的层间黏结、喷嘴碰撞和连续碰撞检测；极端挤出仍可能出现穿插。
- 测试覆盖稳定圆筒、不同跨度的下垂、偏心接触滑移、过量供料、受载压缩、断开和重放。通过这些测试只证明实现边界内的行为，不证明真实陶土参数准确。

## 集体记忆轨迹

当前内置轨迹由 `claude-opus-5-5` 对 1910 条 memories 分 20 批提炼后汇总而成。上传分析前移除了姓名和 embedding 坐标；情绪计划包含十二个节点、代表记忆的索引以及生成版本。用户已确认这组 1910 条语料公开，站点另以 `public/memories.json` 内置 text-only 原文作为默认阅读内容，不包含姓名、日期、embedding 等结构化元数据。该轨迹是为作品进行的戏剧性编排，不代表共同年表、单个人生、统计平均或心理诊断。

运行时不再调用 Agent。`emotionTrajectory.ts` 使用版本化的固定规则，将每层插值后的效价、唤醒度与控制感确定性地映射为现有 `ProcessEvent[]`。当前 `emotion-behavior-2` 只控制供料波动和中断，兼容字段 `sag` 固定为 true，v3 不读取该字段。相同事件、随机种子和材料版本可确定性重放；导出的作品同时保存情绪计划和映射版本，导入旧记录不会重新编译情绪计划或改写历史事件。

```sh
npm test
npm run build
```

浏览器验收需要先启动开发服务器，并安装 Playwright Chromium：

```sh
npx playwright install chromium --no-shell
npm run verify:browser
npm run verify:browser -- --layout-only
npm run verify:material
```

使用 `POTTERY_URL` 指定验收地址。`verify:material` 检查 v3 的暂停、重建、提前结束与存档往返，同时检查 v2/v1 导入；输出材料计算与几何更新耗时。报告保存在忽略提交的 `artifacts/` 中。测试环境使用 Chromium 软件渲染，不能代替真实手机上的帧率验收。

首版不依赖实体打印机或云服务，收藏不跨设备共享。材料行为采用近似模拟，并非真实陶土打印的物理预测。

## 本地记忆播放与沉积实验

工坊自动读取站点内置的 `public/memories.json`，包含用户确认公开的 1910 条**记忆原文**，载入成功立即显示第一条，不再要求每次手动导入。前端通过 Vite 的基础路径请求该静态文件，开发预览、普通生产构建和 `/pottery/` 子路径使用同一数据源；不依赖本机 API、loopback 校验或转发标头。原 ZIP、artifacts、.runtime、.tmuxhub 等工作文件仍禁止经开发服务器静态访问，不因默认语料公开而开放。

载入中、文件缺失或无有效原文时不能开始新打印，可用 `Reload default memories` 重试或 `Choose a JSON file` 手动导入（字符串数组，或带 `activity` / `content` 的对象数组，最多 2000 条）。手动导入/清空优先于迟到的默认响应；清空后不自动重载，刷新重新读取站点默认文件。生产 build/preview 也自动展示这 1910 条原文；本地完成构建不代表公网已部署。

原文不是标题、情绪词或摘要：采用单条轮播，桌面 36px、窄屏和手机 32px 衬线字。自动切换先原位淡出 280ms，再从下方 8px 上浮淡入 500ms；手动翻页使用 650ms 的先淡出后淡入与方向性横移。两条文字不叠加，停稳后静止。长原文可以在当前页内滚动，不截断或改写。

右侧不显示记忆集总标题；当前情绪以小标签显示在 memory 原文下方。自动轮播只跟随打印进度；超过 14 条时按进度选取部分完整原文停留展示，界面标注 `Selected passages`，不会加速刷过全部内容。打印暂停时不再换页，已经开始的过渡可以完成。前后按钮或聚焦阅读区后的左右键可逐条阅读全部原文，首尾不循环；滚轮、触摸阅读和上下键滚动会停留在当前条，中间启停图标恢复跟随，不暂停打印。减少动态效果设置禁用切换动画。普通入口及 `/?physics=strand` 默认使用原 v3 泥条模型；v4 仅作为可选实验。

内置的 1910 条公开原文随站点构建分发；用户自行导入的文件仍直接由浏览器读取，文本仅保留于当前页面内存，不上传、不进入收藏或导出。文件名与记录中的姓名/日期字段不会显示，但原文仍可能包含可识别信息，不声称完全匿名。打印使用预设集体情绪轨迹，原文按文件顺序选取，两者不构成逐条情绪分类或一一配对；导入只改变阅读列表，不会重算情绪轨迹或打印计划。隐私、格式限制和片段选择说明放在信息图标中；主视图不显示长篇说明，首次访问也不自动弹出操作指南。

导航中的 `Lab` 在新标签页打开 `/?lab=deposition`；若工坊正在打印，会先暂停，原标签页的记忆文本和打印过程保留。实验提供单条、三层和断料恢复试样。主工作台现在也能在开始前选择 `Physics → Height field · test`（或打开 `/?physics=heightfield` 预选），把同类压力驱动的体积迁移应用到圆形打印路径；开始后锁定选择，暂停/继续/提前结束、记忆播放和收藏仍可用。默认仍是原 v3，v4 独立版本存档与重建，不改写历史 v1/v2/v3。

v4 渲染单一材料高度场，不再拼接椭圆泥管；它只能模拟平底支撑上的铺展，不能表示悬挑、内部空隙、断裂或真实层沟。用于高筒时超出了浅层假设，可能形成更宽、更矮的环状堆积，**不是已验证的陶土升级，也不是用平滑外观证明真实物理**。详见 [实验说明](docs/deposition-lab.md)。以上接入为本地实验，不代表已经更新公网。

```sh
npm run verify:memories
npm run verify:lab
npm run verify:heightfield
npm run build && npm run verify:default-memories
```

交互与截图验收在导航前拦截 `memories.json`，使用固定虚构原文；`verify:default-memories` 则直接测试真实公开数据在 `/` 与 `/pottery/` 生产构建中的自动载入、开始打印及刷新恢复。`node scripts/verify-local-originals.mjs` 检查当前开发预览是否已就绪，仅报告条数和状态。

## 公网转发

公网入口为 <https://gfyh.fun/pottery/>。Nginx 复用现有 HTTPS 证书，经服务器回环端口 `15173` 的 SSH 反向隧道访问当前节点的 `127.0.0.1:5187`。

材料计算与画廊重建都在浏览器中完成，后者使用一个 Web Worker。公网服务器只转发静态资源；运行时不调用 Agent，也不上传 memories。

```sh
npm run build:public
npm run public:start
npm run public:status
npm run public:stop
```

守护进程管理预览服务和 SSH 隧道，退出后每隔 3 秒重试；SSH 每 15 秒保活，连续 3 次无响应后重连。使用 `~/.ssh/id_ed25519_hpc_peers` 登录 `lizd@gfyh.fun`，启动前需完成主机信任和公钥安装。仅在一个节点启动公网转发；状态和日志位于 `.runtime/public-forward-<hostname>/`，管理命令需在启动节点执行。当前部署节点为 `mgmt-5`。节点关机或重启后需重新启动，不配置开机自启。

公网构建使用 `/pottery/` 基础路径，单独输出到 `dist-public`；不改变原有 `5173` 开发服务。更新时先构建，再停止并启动公网服务。

```sh
POTTERY_URL=https://gfyh.fun/pottery/ npm run verify:browser
```
