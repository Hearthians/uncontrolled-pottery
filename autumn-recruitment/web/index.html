Methods

01 / Statistical base

Sentiment, topics and emotions count only labelled, relevant discussions. Multiple labels can coexist. Posts without an explicit emotion remain in the denominator.

02 / Years and datasets

Years follow the original publication date. Each dataset is compared separately.

03 / Interpreting expression

Model labels describe what the author expresses in a post. Happiness about a life event does not necessarily imply optimism about the job market.

04 / Sample limits

This convenience sample describes the discussions collected. It cannot estimate sentiment across the whole market.
