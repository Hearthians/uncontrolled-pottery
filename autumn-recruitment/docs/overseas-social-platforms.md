# 海外社交平台补充数据可行性核验

核验日期：2026-11-17。目标是为现有微博、小红书的秋招研究补充约 200 条/平台的讨论与情绪数据。本次只做官方文档查阅和少量普通公开 GET 请求，未登录新账号、未绕过访问限制，也未运行批量采集。

**当前可以直接取得少量真实讨论的是 Mastodon 的公开话题时间线；Reddit 更适合作为申请 API 后的英文求职讨论来源。Bluesky 和一亩三分地尚未通过实际访问验证。** 这些平台不能直接替代中文秋招样本：`job market`、`new grad hiring`、`layoffs` 通常讨论海外就业市场，研究时应单独标注语言、地区和招聘阶段。

## 实测结果与选择建议

| 平台 | 本次实际验证 | 访问与历史限制 | 主题适配 | 对约 200 条样本的建议 |
| --- | --- | --- | --- | --- |
| Reddit | 官方 API 参考可读；`r/cscareerquestions` 的普通公开 `search.json` 请求直连与 Windows/Clash 均返回 403，未取得帖子样本 | 采用正式 API 申请及 OAuth 路径后再验证。搜索接口有游标和相对时间窗口，但该参考没有提供可保证任意年份完整检索的独立起止时间参数 | 英文校招、应届生求职、技术就业市场的讨论适配度高；不能直接代表中国秋招 | 优先申请，获准后先试每年数条，再决定能否分配 2022–2026 各 40 条；当前不能承诺已可采集 |
| Mastodon | `hachyderm.io` 的 `#layoffs` 取得 5 条英文帖子，含裁员/AI 替代员工的观点；`#jobsearch` 取得 5 条但全是岗位广告；同实例 `#秋招` 为 0 条 | 公开标签时间线可分页；全文帖子搜索依赖实例后端和认证。各实例的可见与索引范围不同，不能当作全网完整档案 | 适合补充英文裁员、科技行业就业和劳动议题；中文秋招覆盖本次未验证 | 可立即做一个小型英文试采。过滤招聘广告、新闻转发和重复内容后再评估是否足够 200 条，逐年历史配额仍待验证 |
| Bluesky | 官方当前 OpenAPI 可读；`job market` 与 `秋招` 的 2025 年时间窗搜索在直连和 Windows/Clash 均为 403，未取得帖子样本 | 官方说明不同服务实现可能要求认证；时间窗基于 `sortAt`，不一定等于原帖 `createdAt`；游标不保证能遍历全部命中 | 可以尝试英文科技就业讨论；中文秋招密度、2022 年覆盖均未验证 | 有正规账号/API 凭据后做 5 条试采；在历史年份覆盖确认前不纳入固定的五年比较样本 |
| 一亩三分地 | 主页普通公开请求经 Windows/Clash 返回 403，未取得帖子样本 | 本次没有验证可用公开搜索 API、登录后检索或历史正文权限 | 中文海外留学与求职讨论在选题上契合，但样本群体主要是海外求职者 | 如用户已有正常访问权限，可另做人工/RPA 小样本试验；现阶段不把它列为可直接部署的数据源 |

403 只证明本次请求未成功，不能据此确定是认证、网络出口还是站点策略导致。没有继续尝试替代接口、代理轮换或其他规避措施。

## 可复核的请求和样本边界

### Reddit

- 官方参考：<https://www.reddit.com/dev/api/#GET_search>，HTTP 200。
- 样本请求：`https://www.reddit.com/r/cscareerquestions/search.json?q=job+market&restrict_sr=1&sort=new&t=all&limit=5&raw_json=1`，HTTP 403；直连与 Windows/Clash 结果相同。
- 官方 Data API 说明页 <https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki> 本次为 403，因此本文不声称已核实最新配额、收费或审批条件。

官方搜索参考的 `limit` 最大 100，支持 `after`/`before` 游标、`sort`、`restrict_sr`，`t` 为 `hour/day/week/month/year/all`。其中 `before` 和 `after` 是条目标识的分页锚点，不是日期。不能把 `t=all` 解释为可完整下载所有历史数据；也不能把关键词中的年份当作原帖发表年份，年份最终应按 `created_utc` 验证。

`/search` 返回的是链接/主题帖。评论属于另一类讨论单元，需要另外读取所选主题的评论，并保留原主题、父评论关系和评论原始时间。若同时收集帖子和评论，应分别统计，避免把“200 条评论”报告成“200 个独立主题”，也避免一个热门长帖占满样本。

### Mastodon

官方来源：

- 搜索接口：<https://docs.joinmastodon.org/methods/search/>
- 标签和公开时间线：<https://docs.joinmastodon.org/methods/timelines/>

官方说明需分开理解：`/api/v2/search` 本身允许部分匿名调用；**全文 statuses 搜索仍依赖实例的 Elasticsearch 等搜索配置和已认证请求**。不能简单概括为“所有搜索都必须登录”，也不能因为匿名搜索 HTTP 200 就认定已经搜索到了完整帖子库。

| 请求 | 返回 | 返回帖子的 `created_at` 范围 | 本次可支持的结论 |
| --- | --- | --- | --- |
| `hachyderm.io/api/v1/timelines/tag/layoffs?limit=5` | 200，5 条 | 2026-11-13 至 2026-11-15 UTC | 存在可匿名取得的英文讨论样本；涉及裁员、AI、公司运营等观点，其中也含组织宣传，需筛选 |
| `hachyderm.io/api/v1/timelines/tag/jobsearch?limit=5` | 200，5 条 | 2026-11-17 UTC | 5 条均为英文岗位广告，不适合作为求职者市场情绪样本 |
| `hachyderm.io/api/v1/timelines/tag/秋招?limit=5` | 200，0 条 | — | 该实例本次未返回这个标签的帖子，不能外推为整个平台没有中文讨论 |
| `mastodon.social/api/v1/timelines/tag/jobsearch?limit=5` | 200，5 条 | 2026-11-17 UTC | 另一实例也可匿名取得当前标签帖子，主题质量未据此认定 |
| 两个实例 `/api/v2/search?type=statuses&limit=5&q=job market after:2025-08-01 before:2025-11-18` | 均 200，`statuses=[]` | — | 没有取得历史全文样本。这里的日期写在 `q` 字符串内，不是独立 API 日期参数；未验证匿名请求的全文搜索和日期语义 |

`hachyderm.io` 的 10 条非空标签样本均为原始 status，`reblog=null`，且 `in_reply_to_id=null`。它们不是评论样本。只依据原帖 `created_at` 判断日期；招聘广告链接里出现的旧年份不作为帖子的发表年份。

标签时间线单页最大 40，可用 `max_id` 等游标向前翻页。服务器可以关闭公开预览或要求授权。联邦服务器并不天然拥有全部其他服务器的历史内容，因此同一标签跨实例可能重叠，也可能缺失；应按原帖 URI 去重，保留抓取实例。以上近期样本**没有证明 2022–2026 各年都有足量可用讨论**。

### Bluesky

官方当前接口定义：<https://endpoints.bsky.app/openapi.bluesky-app.json>，路径 `/xrpc/app.bsky.feed.searchPosts`。原文档 URL <https://docs.bsky.app/docs/api/app-bsky-feed-search-posts> 本次跳转到官方接口文档站。

分别用 `q=job market`、`q=秋招`，`since=2025-08-01T00:00:00Z`、`until=2025-11-18T00:00:00Z`、`limit=5`、`sort=latest` 请求 `public.api.bsky.app`，两次均 403；经 Windows 原生请求和 Clash 复核仍为 403。返回的是 Forbidden 页面，不能直接解释为官方 JSON 的 `AuthMissing`。

官方定义允许单页 1–100 条，支持 `since`（含）、`until`（不含）和游标，但明确说明：

- 部分服务商和实现可能要求认证。
- 时间窗依据 `sortAt`，可能不同于 `createdAt`。落库时仍需复核原帖发表时间。
- 游标不一定能遍历全部结果，`hitsTotal` 可能截断或取整。

因此，即使后续认证成功，也只能报告实际取得的、可追溯的方便样本；不能声称搜索结果构成完整历史档案。2022 年是否有满足本题目的可用帖子，本次未取得证据，不能用较近年份补齐后仍称为“五年对比”。

### 一亩三分地

`https://www.1point3acres.com/bbs/` 经 Windows/Clash 普通 GET 返回 403。Linux 的普通请求在网络连接阶段失败，两者应分别记录，不能合并解释为账号无权限。

若后续使用用户正常登录的浏览器，先人工确认 2022–2026 各年主题检索、原帖时间及正文可见性，再判断 RPA 的投入。主题帖和楼层回复分别计数；需要额外积分、付费或访问权限的内容以实际已有权限为边界。本次没有登录该站，也没有对其正文或 API 可用性作进一步结论。

## 与现有研究衔接

建议中文秋招主样本继续来自微博、小红书；海外平台作为独立的英文就业市场比较组。一亩三分地若可正常访问，可作为“中文海外求职”单独分组。不要直接比较这些群体的负面情绪比例来推断某地就业市场好坏。

若目标为五年共约 200 条/平台，可先规划每年 40 条，按实际原帖时间和多个招聘议题分层。进入正式采集前，每个平台先验证各年 3–5 条真实、相关、可读取的记录；不足年份明确报告缺口。2026 年当前只能覆盖到核验日，与其他年份对比时应统一截止日。

字段沿用现有规范，并增加或保留 `language`、`market_region`、`discussion_type`（主题帖/评论）、`parent_id`、`original_uri`、`source_instance`、`retrieval_query`、`collected_at`。分析前剔除岗位广告、培训营销、纯转载、重复原帖和无市场评价的内容。对裁员新闻的情绪与求职者自身体验可分别编码，再使用现有模型接口进行主题与情绪标注。

实测原始响应、请求结果与核验时间保存在被 Git 忽略的 `data/diagnostics/overseas-social-*`；本文只记录汇总，不包含账号标识、凭据或个人信息。未取得内容的平台不计入已完成的样本量。
