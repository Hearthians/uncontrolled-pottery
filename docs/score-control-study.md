# 0–1 得分与主导形态：三路控制实验

本地入口：`/?lab=score-study`。这是独立对照页，输入一个 0–1 的数，查看同一标称器形在三种控制方式下的结果。提供六档并排试样、任意得分生成、旋转／缩放／背面查看、正面 PNG 和得分／测量 JSON 导出。

英文公开入口：<https://gfyh.fun/pottery/?lab=score-study>，主工坊的 `Form` 导航可进入。界面、无障碍标签、错误提示及下载记录中的方案说明均使用英文；导出 JSON 使用 `controlWeights` 记录当前控制权重。连续控制修订版的发布记录位于 `artifacts/score-study-revision/deployment.json`，原发布记录保留在 `artifacts/score-study/deployment.json`；线上 `release.json` 标识当前发布。静态资源先上传，保留旧哈希资源后原子替换入口，发布不重启分析服务。

## 共同输入与比较边界

固定种子 42、64 圈、每圈 128 个采样，共 8,193 个连续螺旋点。标称参考半径 43 mm、圈距 2.7 mm，截面半轴 3.3 / 1.85 mm。基形有三个缓慢扭转的起伏，得分不改变基形的选择或随机种子。基础两圈保持连续，局部变化平滑引入。参考图用于确定形态语言，没有使用参考图推断真实陶土材料参数。

三路共用标称路径、渲染器、视角和材质，但**不是三个经过统一物理标定的求解器**：A 使用既有 v3 泥条模型，B／C 是不同的有界几何生成器。A 的接触压扁仍沿用原 v3 约 1.92 mm 的层高，与新标称圈距不一致；即使零得分，最终外观高度也会从约 177 mm 压缩到约 135 mm。因此这是一组控制机制与视觉行为探索，不能据此作严格的材料性能比较。

## 三路结果

| 方案 | 控制方式 | 本轮观察 |
| --- | --- | --- |
| A：供料与中断 | 固定喷嘴路径与材料，修改相关供料波动、中断和局部增料；沿用压力／流量响应及 `ClayStrand` | 能产生粗细与缺料；中高分响应不稳定。0.8 比 1.0 碎裂得多，没有形成可靠的阶段顺序 |
| B：供料与走线 | 成片缺口、堆料、实际走线偏移；随后用固定几何支撑规则松弛 | 能形成明显鼓包、错层和下垂；缺口会被沉降部分闭合，0.6 已伴随约 8.7 mm 的局部下移 |
| C：连续形变场 | 先构造同一种子的强失稳目标，再由得分连续缩放位移与截面变化；固定区域逐渐缩颈并断开 | 鼓包、错层和下垂在整个 0–1 区间共同增强，没有分段启用或中间平台；独立积料区域使鼓包不再依赖缺口形成 |

本轮优先推荐 C 作为“得分 → 形态”原型，保留 B 作为支撑传播更明显的对照。C 中的得分表示同一形态场的强度，不表示先后发生的阶段，也不是打印时间。页面六列只标示 Stable、Subtle、Mild、Moderate、Strong、Extreme 六个强度样本，任意中间得分使用相同规则。

## 如何生成

`scoreStudyCore.ts` 定义共同器形、A／B 使用的阶段权重和几何测量；当前实验版本为 `scalar-form-study-2`。`scoreSupplyTrial.ts`、`scorePathTrial.ts`、`scoreFieldTrial.ts` 实现三种控制。C 使用独立的连续控制，五项控制权重均等于输入得分，不再使用 A／B 的阶段门限。局部缺口和积料以固定的角度／高度区域编排，邻层共同变化；相同种子不会随得分重新抽选特征位置。

C 为每个种子构造一个强失稳目标：完整墙面上的紧凑多圈积料同时向外鼓出并增加椭圆截面，局部层带发生偏移与弯折，悬空区域通过局部几何支撑查询产生有界下垂。随后从标称器形到目标线性插值每个路径点的位置；未缩颈区域的截面半轴也线性插值。因此低分、中分、高分使用同一组特征，增大得分会逐步加强已有变化。

缺料区域使用固定连续场逐步缩小泥条截面，截面趋于零后才标为断开，避免直接删除一整段粗泥条产生明显跳变。截面面积、开口面积和几何测量值不要求与得分严格成正比。局部支撑只在构造强失稳目标时求解，得分变化不会重新触发支撑分支；这保证形态控制的连续性，并不代表中间得分都经过独立的材料平衡求解。泥条网格保留椭圆截面，在实际断开处添加圆钝端头，不跨孔洞连接。

三路各用一个 Worker，A 的较慢材料计算不会阻塞 B／C 交互。本机 Node 初轮 A 六件约 86 秒，B／C 每件约十几到几十毫秒；浏览器数值和耗时可能不同，A 极端失稳尤其对浮点误差敏感。静态图由同一离屏渲染器逐件生成，避免为 18 张图保留 18 个 WebGL 上下文。

## 验证与限制

```sh
npm test
npm run build
npm run dev -- --port 5198
node scripts/verify-score-study.mjs
```

`POTTERY_URL` 可以指定已有开发／生产预览地址。浏览器验收输出在忽略提交的 `artifacts/score-study/`：`comparison.png`、三行六档对照、单件正／背面、桌面／手机截图和 `browser-report.json`。环境若以本地库启动 Chromium，需要在运行命令前提供相应 `LD_LIBRARY_PATH`。

单元检查覆盖共同零输入、确定性、基础圈、连贯缺口、完整积料区域的截面增长、全得分范围的有限坐标与形态边界，以及相邻得分之间的位置连续性和全区间线性位移。浏览器检查实际 18 件渲染、任意得分、旋转、背面、视角重置、移动端布局和无 API 请求。通过这些检查不表示体积守恒、无穿插、可打印或真实陶土流变已获验证。

当前以连续加强的鼓包、偏移和悬垂表达失稳，仍保留清晰的泥条堆叠感。参考图中细丝、滴挂、层间融合和湿泥局部破裂的表面质感并未完整实现。

## 离线视频

`node scripts/render-score-video.mjs` 先离线求解并保存 300 份 C 方案几何，然后由这些记录渲染 300 张 1920×1080 PNG。第 `i` 帧的得分为 `i / 299`，旋转角为 `−π + 2.5 × 2π × i / 299`。起始背面、结束正面；相机与照明固定。连续控制修订版每帧使用独立得分的完整几何记录，整个区间没有阶段平台。

视频为 H.264／yuv420p，30 fps、300 帧、10.000 秒，带烧录英文字幕、可选英文字幕轨和单独 SRT。字幕依次为 `One score. Continuous change.`、`Clay swells and layers drift.`、`Bulges and bends grow together.`、`The same form, increasingly unstable.`。这些字幕描述共同增强的形态，没有把各效应定义为依次启用的阶段。当前得分持续显示于右上角。

连续控制修订版使用 `SCORE_VIDEO_DIR=artifacts/score-study-revision/video` 生成，成品为该目录下的 `grammar-of-failure-c-10s.mp4`；部署后的公开副本为 `https://gfyh.fun/pottery/media/grammar-of-failure-c-continuous-10s.mp4`。原版成品保留在 `artifacts/score-study/video/`。修订版同目录保留 `geometry/`、`frames/`、`manifest.json`、字幕、封面和从成品解码的分镜预览。清单记录每帧得分、角度、坐标文件／PNG 哈希与几何测量，及离线计算、捕获和编码的时间顺序。脚本需要可用的 FFmpeg／FFprobe；可通过 `SCORE_VIDEO_FFMPEG`、`SCORE_VIDEO_FFPROBE` 指定路径。默认拒绝覆盖已有清单；`SCORE_VIDEO_RESUME=1` 仅在几何与渲染源码指纹、保存几何哈希及逐帧渲染记录一致时恢复，并保留原计算时间。修改几何或渲染源码后应使用新目录。
