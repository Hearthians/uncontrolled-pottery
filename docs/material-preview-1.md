# 材料模拟预览版 1

版本：`1.1.0-preview.1`。分支：`feat/material-deposition`。旧版回退标签：`v1.0.0`，对应 `029e03b`；主分支保留基线与调研文档。

## 本次范围

- 固定螺旋工具路径；欠供料期间喷嘴空走，不追随泥料凹陷。
- 气压与流量有有限响应时间，停止后保留余流；事件按固定模拟步长推进，暂停冻结模拟时间。
- 沉积量决定泥条截面，接触后压扁；低流量先变细再断开，恢复时计入喷嘴残留体积。
- 查找下方可用支撑和短跨距两侧锚点；最近沉积区渐进下垂，过载可唤醒旧支撑区。旧材料的出生体积保留，位置可以继续变化。
- 缺口有端面，截面和法线随局部形态改变；喷嘴与可见出料短段独立更新。紧凑索引省略缺失泥条的三角形。
- 画廊重建进入浏览器 Web Worker，避免同步重建整件作品阻塞模型加载进度与界面。
- 新记录使用模拟版本 2；旧记录继续使用原算法。支持两版 JSON 导入、导出、收藏与刷新重建；未知版本拒绝导入。

手势映射、首次引导、自动模型预加载、真实下载进度与摄像头按需授权延续旧版。页面只增加画廊的导入图标和收尾状态。

## 配置与边界

配置标识为 `pneumatic-clay-1`，描述气压直挤湿泥近似，并不代表某一厂商的现售设备。为保留原界面的圆筒高宽比例，首次实现采用 100 mm 直径、6 mm 喷嘴、约 1.92 mm 层高、25 mm/s 路径速度；这调整了调研方案中用于校准的 3 mm / 1 mm 候选尺寸。

每圈 160 个采样，64 圈，固定步长约 0.07854 秒；路径结束后最多 240 tick 收敛。默认末尾 96 个路径采样内停料并释放余流，完整体验约 55 秒，对应约 823 秒模拟过程。提前结束也会经过有限余流与收敛，随后才能收藏。

当前只做竖向局部变形和截面变化。没有横向接触滑移、泥条盘曲、完整黏弹塑性求解、整体失稳、干燥或烧成。支撑查询利用固定圆筒的角度索引向下查找，适用于本版路径，不能直接推广到任意 G-code。气压、流变曲线、响应时间、承载与弯曲系数均为待实机标定的经验参数。

极端欠供料可能使器壁显著降低，随后泥料落向已有支撑或平台；不会为保持完整圆筒而自动补料。较弱终止余流可能留下不完整的最后一圈。

## 验收与资源

26 项单元测试通过。行为测试覆盖零扰动基准、供料脉冲与响应、按记录重放、不同推进批次的一致性、体积账目、固定喷嘴路径、旧材料体积不变、有限下垂、暂停、提前结束及旧版兼容。TypeScript 与开发、公网两种生产构建均通过；主包仍有 Vite 的大于 500 KB 提示。

浏览器验收覆盖完整打印、桌面与手机尺寸、画布像素与旋转、收藏、图像导出、两版过程导入与刷新回放、异步重建期间启停和反复进出画廊，以及真实 MediaPipe 检测管线、丢手暂停、摄像头释放、自动加载、缓存和失败重试。

发布至 <https://gfyh.fun/pottery/> 后另行验证 `/pottery/` 下的 Worker、WASM 与手势模型路径、桌面与 390 px 手机画布、自动预加载、实时调参、暂停与提前结束。页面无运行错误或失败请求，公网转发守护进程正常。测试使用浏览器构造的相机视频帧，不代表已验证现场照明与真人手势的识别率。

材料与手势都在访问者设备运行，公网服务器只继续提供 Nginx 与 SSH 静态转发，没有新增服务端求解、推理或摄像头上传。新增应用代码与 Worker 合计约 21 KB 未压缩，不增加手势模型大小或持续网络请求。

本机 Node 24 对强扰动完整流程的抽样：三 tick 推进 p95 约 0.22 ms，模拟对象堆增量约 4.28 MiB。这不包含浏览器、渲染与手势模型。单场景网格 CPU TypedArray 约 5.43 MiB，GPU 另有位置、法线、颜色与索引副本；不含阴影图、渲染目标、收藏缓存、Worker 和其他场景。

Chromium 软件 WebGL 的实测如下，计时包括固定步长材料计算和网格 CPU 更新，不含 GPU 完成时间与手势模型自身耗时：

| 情景 | 样本数 | 平均 | p95 |
| --- | --- | --- | --- |
| 强波动 / 欠供料，包含多次画廊切换 | 88 | 4.64 ms | 8.00 ms |
| 真实手势检测管线同时运行 | 116 | 1.74 ms | 4.90 ms |

前一个样例中，材料计算 p95 为 6.80 ms，网格更新 p95 为 1.40 ms。两组输入和推进批次不同，不能直接用来推断手势检测能降低耗时。4 ms 的原始目标尚未达到，也未完成整页新增内存、Worker 峰值和真实手机帧率的验收。性能仍需在展览电脑与目标手机上确认。

公网服务器采样时的 Nginx worker RSS 约 10.3 MiB / 个；这是现有进程占用，不是新增模拟的开销。没有修改 Nginx、安装服务端模型或新增后台求解进程。

## 回退

首次发布前的完整线上静态构建备份在 `artifacts/releases/v1.0.0/`，不提交模型等生成资源。要恢复线上旧版，可在当前节点执行：

```sh
npm run public:stop
cp -a artifacts/releases/v1.0.0/. dist-public/
npm run public:start
```

此操作替换静态入口及旧版资源，不改当前分支。旧版仍能读取自身的收藏，但不能重建新版材料作品；回退期间保留新版 JSON 导出作为备份。再次运行 `npm run build:public` 可以重新构建当前分支版本。
